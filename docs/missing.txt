Manager Approval Workflow Instructions This workflow ensures accountability, oversight, and formalizes the completion of the Missing/Incident Report, satisfying the requirement that all reports must be forwarded to managers for approval 1 . A. Phase 1: Submission (Staff Member Action) Step Action System Output 1. Staff Saves Report The reporting staff member completes the "Focus Missing/Incident Report" and clicks "Submit for Approval." The report is saved permanently to the young person's file with the Report Status: Pending Approval 2 . 2. System Notification The system identifies the designated Manager for the young person/staff member. An immediate email notification is sent to the Manager with: A link to the report for review and Key summary details (e.g., Child's Name, Date/Time Reported Missing). 3. Access Control The report becomes read-only for the originating staff member and editable only for the Manager. B. Phase 2: Manager Review and Decision The Manager accesses the report via the platform's Approval Queue/Dashboard . Decision System Action Report Status Update Consequence 1. Approve The Manager clicks "Approve." They can optionally add a note (e.g., "Good detail captured."). Approved (Final Status) The report is locked as complete. The approval time stamp is recorded: approval_dt . 2. Reject/Query The Manager clicks "Reject/Query." They must enter mandatory notes detailing the required edits (e.g., "Police reference number is missing," or "Key Findings section needs more detail"). Draft / Query Required The report status reverts to Draft . An email is automatically sent back to the original reporting staff member detailing the rejection notes. The staff member can now edit the report. C.
