 Focus Documents Upload To implement the Uploaded Documents module within the FocusCMS platform, follow the technical specifications outlined below. The goal is to create a categorized, secure, and audited document management system. 1. UI/UX Requirements Module Name: Uploaded Documents . Placement: Add a new navigation item in the primary dashboard sidebar. Upload Interface: Implement a "New Upload" modal or dedicated page. Mandatory Field: A text input for "Document Name". The save button must remain disabled until a name is provided. Category Selection: A required dropdown menu containing the following predefined categories: Health, Legal, Identification, Education, Employment, Finance, Official Document, Pathway Plan, Referral , Accommodation and Other. Action Tracking: Include a toggle or checkbox for "Task Action Required" upon upload to trigger a follow-up workflow. Ability to Email directly from this section . This will be a “permissioned based area” dependent on access rights 2. Backend &amp; Validation Logic Uniqueness Constraint: Implement a pre-save check. The system must not permit duplicate filenames within the same category for a specific record. If a duplicate is detected, return a 409 Conflict error with a user-friendly message: "A document with this name already exists in this category." Audit Metadata: Every file object in the database must automatically capture and store: uploaded_at : ISO 8601 Timestamp. uploaded_by : The UUID and Full Name of the authenticated user performing the action. Storage: Documents should be stored in a secure cloud bucket (e.g., AWS S3 or Netlify Blobs) with access restricted to authenticated sessions. 3. Data Table View Create a searchable and filterable table to display the documents with the following columns: Document Name (Clickable to download/view). Category (Labelled with distinct badge colors for each type). Date Uploaded (Format: DD/MM/YYYY HH:MM). Uploaded By (User name). Action Status (Icon indicator if a "Task Action" was flagged). 4. Developer Instructions for Task Action If the "Task Action" option is selected during upload, the system should append a record to the Tasks table or trigger a notification hook to the relevant supervisor, linking directly back to the uploaded document. 5. Security Ensure server-side file type validation to restrict uploads to safe formats (PDF, DOCX, JPG, PNG). Enforce Role-Based Access Control (RBAC) so only authorized staff can delete or modify these records.
